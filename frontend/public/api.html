给 AI 的使用说明

脚本请求请设置描述性的 User-Agent（例如 YourNewsReader/1.0）；默认 Python 客户端可能被 Cloudflare 返回 403。无需登录或 API Key。

读取 data/latest.json 后，按公司、时间和市场筛选 items。按 company_ids 关联公司，或直接读取 data/companies/{company_id}.json。title_zh、summary_zh 是中文标题与摘要；title、excerpt 保留原文。保留原文链接。

JSON 保留全部报道。event_id 表示同一事件分组，related_article_ids 列出其他报道；请先按公司和市场筛选，再分组。editorial 是 AI 分类，仅 category=marketing 且 confidence=high 的内容在阅读器默认收起，未分类或不确定的内容正常展示。分组 ID 只用于当前快照。

published_at 是来源发布时间；为空时不要把 first_seen_at 当成发布时间。检查 last_success_at、collection_status 和 sources，避免把旧快照当作最新消息。

接口返回静态 JSON，查询参数不会执行服务端筛选。保留最多 1,500 条、最近 30 天的新闻。市场标签基于别名和来源范围，非全市场覆盖。

计划每 2 小时采集，可能延迟；AI 每 6 小时最多生成一次，失败时保留旧结果。
